# 3. 개발 환경 설정 가이드

이 문서는 팀원이 새 PC에서 저장소를 받아 개발을 시작할 때 따라 하는 가이드입니다.

## 사전 준비물

- Python 3.10 이상
- Node.js 18 이상 (npm 포함)
- Git
- (추후 DB 연동 단계에서 필요) Docker Desktop — 아직은 설치만 해두면 됨, 지금 단계에서는 사용 안 함

## 1. 저장소 클론

```powershell
git clone <repo-url>
cd DocuMind_AI
```

## 2. Backend 실행

```powershell
cd backend
py -m venv venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

- Mac/Linux는 `.\venv\Scripts\Activate.ps1` 대신 `source venv/bin/activate`
- 확인: http://localhost:8000 (Hello 메시지), http://localhost:8000/docs (Swagger 문서)

> `venv/` 폴더는 git에 올라가지 않습니다(`.gitignore`). 각자 PC에서 위 명령으로 새로 만들어야 합니다.

### 자주 나는 오류

- PowerShell에서 `Activate.ps1` 실행 시 "이 시스템에서 스크립트를 실행할 수 없으므로..." 오류
  → 아래 명령 실행 후 다시 시도 (현재 터미널 세션에만 적용)
  ```powershell
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  ```
- `pip freeze > requirements.txt`로 저장한 파일이 글자마다 깨져 보임 (윈도우 PowerShell 기본 인코딩 문제)
  → 아래처럼 인코딩을 지정해서 다시 저장
  ```powershell
  pip freeze | Out-File -Encoding ascii requirements.txt
  ```

## 3. Frontend 실행

```powershell
cd frontend
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
npm install
npm run dev
```

- 확인: http://localhost:3000 (Next.js 기본 페이지)

> `node_modules/`, `.next/` 폴더도 git에 올라가지 않습니다. 각자 `npm install`로 새로 설치해야 합니다.
